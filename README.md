# Robiyar
 Robiyar is an Android application for performing various tasks and activities on the Rubika messaging platform

 ## Features 
 The application is currently under development 

 Planned and implemented features include : 

 - post views []
 - Channel membership []
 - group membership []
 - poll status []
 - Rubino likes []
 - Rubino views []
 - Rubino followers []
 - Other Rubika-related tasks []

  ## Technologies 
   - kotlin
   - Android  SDK
   - xml
   - MVVM
   - Retrofit
